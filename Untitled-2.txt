\begin{tcolorbox}[infobox]
\textbf{Objetivo del documento.}
Este documento presenta un análisis preliminar de tres posibles proyectos de tesis vinculados con propuestas de la UTEC de Uruguay. El objetivo no es plantear una solución definitiva, sino comprender cada propuesta, su relación con líneas de investigación, el potencial de desarrollo y las principales ventajas y dificultades de cada opción.
\end{tcolorbox}

\bigskip

% =====================================================
\section{Proyecto 1 — Simulador de manufactura flexible para Industria 4.0}

\begin{tcolorbox}[infobox]
\textbf{Idea general.} Diseñar un sistema que simule productos personalizables dentro de una línea de manufactura didáctica (Dolang DCIM-900). Cada producto tendría una configuración propia —tipo, color, recorrido, operaciones— y el sistema mostraría cómo la línea se adapta a cada uno. Abarca conceptos de Industria 4.0, trazabilidad y sistemas ciberfísicos.
\end{tcolorbox}

\vspace{6pt}
\textbf{Relación con UTEC.} Se vincula con las líneas de automatización, Industria 4.0 y manufactura flexible. La plataforma educativa sería el vehículo para mostrar cómo una línea automatizada toma decisiones a partir de información digital (PLC, sensores, comunicaciones).

\vspace{6pt}
\textbf{¿Qué se haría?} Una interfaz para configurar el producto, que luego envía datos al sistema didáctico (por ejemplo, vía RFID, QR o NFC). El sistema ejecutaría distintos recorridos según la configuración, demostrando personalización y trazabilidad a escala didáctica.

\vspace{8pt}
\begin{multicols}{2}
\begin{tcolorbox}[probox]
\begin{itemize}
  \item Sólida integración de automatización, software, sensores y comunicaciones.
  \item Fuerte relación con Industria 4.0 y valor educativo elevado.
  \item División natural entre dos integrantes (software / control).
  \item Atractivo para presentar en defensa.
\end{itemize}
\end{tcolorbox}

\columnbreak

\begin{tcolorbox}[contrabox]
\begin{itemize}
  \item Depende del acceso real al sistema Dolang/DCIM-900.
  \item Documentación limitada puede dificultar la integración.
  \item Sin el equipo físico, el proyecto pierde sustancia.
  \item Riesgo de crecer demasiado si se imita un sistema industrial completo.
\end{itemize}
\end{tcolorbox}
\end{multicols}

\begin{tcolorbox}[evalbox]
Propuesta de alto nivel tecnológico. Su factibilidad depende principalmente de la disponibilidad del equipamiento y los permisos para trabajar sobre él. Requiere confirmar el acceso antes de comprometerse.
\end{tcolorbox}

\section{Proyecto 2 — Monitoreo de cadena de frío en transporte de alimentos}

\begin{tcolorbox}[infobox]
\textbf{Idea general.} Desarrollar un sistema IoT para monitorear la cadena de frío durante el transporte de alimentos (especialmente cárnicos). El dispositivo registraría temperatura, humedad, ubicación y eventos relevantes del traslado, con alertas en tiempo real y registros para trazabilidad.
\end{tcolorbox}

\vspace{6pt}
\textbf{Relación con UTEC.} Se enmarca en las líneas de IIoT, Big Data y supervisión de procesos. Aplica tecnologías de monitoreo remoto a la digitalización del sector agroindustrial uruguayo.

\vspace{6pt}
\textbf{¿Qué se haría?} Un dispositivo IoT instalado en el vehículo o viajando con la carga, que mida temperatura, humedad y posición GPS y envíe datos a una plataforma web. La plataforma mostraría el recorrido, evolución de variables, alertas y reportes de cada viaje. La validación sería en prueba piloto o condiciones simuladas.

\vspace{8pt}
\begin{multicols}{2}
\begin{tcolorbox}[probox]
\begin{itemize}
  \item Aplicación real y de alto impacto en la industria alimentaria.
  \item Integra IoT, sensores, comunicación remota y visualización.
  \item Sistema escalable con posibilidad comercial.
  \item Relevancia productiva clara.
\end{itemize}
\end{tcolorbox}

\columnbreak

\begin{tcolorbox}[contrabox]
\begin{itemize}
  \item Alcance puede volverse excesivo para dos personas.
  \item Requiere acceso a vehículos o empresas para validar.
  \item Depende de conectividad, cobertura y autonomía del dispositivo.
  \item Si se enfoca en la web, puede perder contenido mecatrónico.
\end{itemize}
\end{tcolorbox}
\end{multicols}

\begin{tcolorbox}[evalbox]
Gran potencial de impacto real, pero debe acotarse con claridad. Lo más viable es un prototipo funcional con validación piloto. El objetivo de cubrir todo el territorio uruguayo excede el alcance de una tesis de dos personas.
\end{tcolorbox}

\section{Proyecto 3 — Fertirrigación automatizada en cultivos bajo invernáculo}

\begin{tcolorbox}[infobox]
\textbf{Idea general.} Construir un sistema de fertirrigación automatizado a escala de laboratorio para cultivos en invernadero. Mediante sensores de humedad, temperatura, pH y conductividad eléctrica, el sistema controla automáticamente el riego y la dosificación de nutrientes.
\end{tcolorbox}

\vspace{6pt}
\textbf{Relación con UTEC.} Se vincula con instrumentación y actuación en sistemas ciberfísicos y con la aplicación tecnológica en el sector agroproductivo: mejor uso del agua, reducción de desperdicios y control preciso del cultivo.

\vspace{6pt}
\textbf{¿Qué se haría?} Un banco de pruebas con recipientes de cultivo, tanques (agua y nutrientes), bomba, válvulas, sensores y controlador. El sistema mide condiciones y activa riego/dosificación según necesidad, con visualización en un dashboard simple.

\vspace{8pt}
\begin{multicols}{2}
\begin{tcolorbox}[probox]
\begin{itemize}
  \item Más realizable a escala de laboratorio.
  \item Fuerte contenido mecatrónico: sensores, actuadores, control, hidráulica.
  \item No depende de empresas externas.
  \item Resultados verificables con pruebas reales.
  \item Fácil de dividir entre dos integrantes.
\end{itemize}
\end{tcolorbox}

\columnbreak

\begin{tcolorbox}[contrabox]
\begin{itemize}
  \item Puede percibirse como acotado si no se añade una capa tecnológica adicional.
  \item Los sensores de pH y CE requieren calibración rigurosa.
  \item Validar resultados agronómicos reales lleva tiempo.
  \item Hay que evitar prometer optimización completa del cultivo.
\end{itemize}
\end{tcolorbox}
\end{multicols}

\begin{tcolorbox}[evalbox]
La opción más viable para dos integrantes. Puede verse más acotada, pero tiene la ventaja de que se construye, se prueba y se defiende con resultados concretos. Agregar una extensión tecnológica —como un gemelo digital básico— eleva significativamente el nivel del trabajo.
\end{tcolorbox}

\section{Ampliación propuesta: Fertirrigación + Gemelo Digital}

\begin{tcolorbox}[extbox]

\begin{center}
\large\bfseries\color{azulAccento}
Sistema de fertirrigación automatizado con gemelo digital básico\\
para asistencia en la toma de decisiones en cultivos bajo invernáculo
\end{center}

\vspace{8pt}
\textbf{¿Por qué esta combinación?}
Agregar un gemelo digital al proyecto de fertirrigación lo transforma de un sistema de riego automático en una plataforma de monitoreo, análisis y recomendación. El resultado es más completo sin ser irrealizable.

\vspace{8pt}

\begin{multicols}{2}
\textbf{Variables representadas en el gemelo:}
\begin{itemize}
  \item Humedad del suelo/sustrato
  \item Temperatura y humedad ambiente
  \item pH de la solución
  \item Conductividad eléctrica
  \item Volumen de agua aplicado
  \item Estado de bomba y válvulas
  \item Historial de riegos y alertas
\end{itemize}

\columnbreak

\textbf{Funciones de predicción y recomendación:}
\begin{itemize}
  \item Estimación del próximo riego necesario
  \item Comparación con receta esperada
  \item Simulación de escenarios de riego
  \item Detección de tendencias anómalas
  \item Recomendaciones básicas: regar, esperar, corregir pH, revisar nutrientes
\end{itemize}
\end{multicols}

\vspace{8pt}
\textbf{Arquitectura (edge/fog computing):}

\vspace{4pt}
\begin{center}
\begin{tikzpicture}[
  every node/.style={rounded corners=4pt, font=\small},
  box/.style={draw=azulUNER, fill=fondo1, minimum width=2.5cm, minimum height=0.75cm, text centered, align=center, inner sep=4pt},
  arrow/.style={->, thick, color=azulClaro}
]
  \node[box] (s) {Sensores y\\actuadores};
  \node[box, right=1.2cm of s] (c) {Controlador\\local};
  \node[box, right=1.2cm of c] (d) {Dashboard /\\Gemelo digital};
  \node[box, right=1.2cm of d] (n) {Nube\\(opcional)};
  \draw[arrow] (s) -- (c);
  \draw[arrow] (c) -- (d);
  \draw[arrow] (d) -- (n);
  \draw[arrow] (c) -- ++(0,-0.8) -| (s);
\end{tikzpicture}
\end{center}

\vspace{8pt}
\textbf{Límites recomendados} (para mantener el proyecto viable):
\begin{itemize}
  \item No modelar la fisiología completa de la planta ni predecir rendimiento comercial.
  \item No implementar IA avanzada como objetivo principal.
  \item No controlar múltiples nutrientes por separado desde el inicio.
  \item No escalar a un invernadero industrial real.
\end{itemize}

\vspace{4pt}
\textbf{Lo que sí es viable construir:} banco de fertirrigación funcional · medición de variables críticas · control automático básico · registro histórico · dashboard con gemelo digital · recomendaciones y predicciones simples.

\end{tcolorbox}
